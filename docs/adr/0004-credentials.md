# Named profiles and STS ownership

Status: accepted foundation decision under the supplied implementation plan.

STS owns signed/reference issuance, resolution, exchange and revocation. Only verifiers persist. One registered intended audience; profiles explicitly choose immediate online or bounded offline guarantees. Source secrets remain contained.

Sources: original design §§2, 23–25, 40–42; addendum §§2–19. Open runtime choices remain in `../architecture/unmapped.md`.
