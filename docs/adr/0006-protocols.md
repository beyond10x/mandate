# Protocol adapters and deferred choices

Status: accepted foundation decision under the supplied implementation plan.

S256 authorization-code/PKCE is initial public-client policy. OAuth product routes remain separate from generated command OpenAPI. Transitive chains and device authorization are deferred. Backend, policy, key provider, sender constraints and audit retention remain explicit decisions.

Sources: original design §§2, 23–25, 40–42; addendum §§2–19. Open runtime choices remain in `../architecture/unmapped.md`.
