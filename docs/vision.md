# Vision

Mandate gives humans, services, workloads and agents stable identities and constrained authority across organizations. Resource services own business state and enforce a small authorization interface. Mandate owns security topology, identity linking, policy, delegation and credential lifecycle.

Success means a tenant administrator changes access without redeploying a resource service; an agent cannot exceed its ceiling even when acting for an administrator; each decision remains attributable to subject, actor, execution and policy revision. Authentication, directory state, tenancy and authorization remain distinct.

This milestone publishes the design and executable contract foundation, not a working identity provider. Authentication and authorization are parallel implementation tracks after canonical contracts stabilize. STS authority-bearing exchange joins both tracks. Identity migration, releases and deployments are outside scope.
